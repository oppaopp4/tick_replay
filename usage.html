歩値CSVリプレイ（多機能版）の使い方

SBI証券 Brisk からダウンロードした歩値CSV（約定ごとのCSV）をブラウザだけで読み込み、歩み値・ローソク足・VWAP・各種インジケーターを当日の時間の流れに沿ってリプレイするデイトレ振り返りツールです。 仮想売買機能で、リプレイを見ながらエントリー・利確・損切りの練習もできます。

CSV はブラウザ内でのみ処理され、外部サーバーには送信されません。データはページを閉じると消えます。

1. Brisk から歩値CSVをダウンロードする

  1. SBI証券にログインし、国内株式 → Brisk を起動します。
  2. 銘柄を表示し、「歩値」タブから CSV をダウンロードします。
  3. ファイル名は Brisk のダウンロード名のまま qr-<銘柄コード>-<YYYYMMDD>.csv（例: qr-7203-20260917.csv）にしておくと、銘柄コード・日付・銘柄名が自動で入ります。 285A のような英字入りコードにも対応しています。

CSV の列は「値段, 株数, 金額, 時刻」（UTF-8、時刻は秒精度）を想定しています。列の順番はヘッダー名から自動で判定します。

2. 基本的な使い方

  1. ① 銘柄CSV にリプレイしたい銘柄の当日CSVを指定します（主役チャート）。
  2. 必要なら ② 参照CSV に同じ日の参照銘柄（通常は 1570 日経レバ）のCSVを指定します。地合い判定・RS・日経換算に使います。省略可。
  3. 前日終値 を手入力します（任意。前日比の表示にだけ使います。CORS の制約で自動取得はしていません）。
  4. ▶ 再生 を押すとリプレイが始まります。もう一度押す（または Space）と停止します。

画面の見方

  • 左：歩み値テープ。約定ごとに値段・株数・金額（億円）・時刻を追加します。上昇＝赤、下落＝緑 の日本式配色です。
  • ヘッダーに現在値・前日比・VWAP・VWAP乖離・時刻を表示。「株探時系列」「株探基本」から株探の該当銘柄ページを開けます。
  • 銘柄チャート：ローソク足（陽線=赤 / 陰線=緑）、VWAP（グレー）、SMA5（赤）/ SMA25（緑）、出来高（直前の足より増えれば赤、減れば緑）。現在値にはオレンジの破線と右端の価格ラベル。
  • チャートにカーソルを乗せると、その足の 時刻 / OHLC / 出来高 / VWAP / SMA / SQZ / RS / E/H / 日経換算 をチャート見出しの右側に一行で表示します。カーソルを外すと最新の足の値に戻ります。
  • 参照チャート：参照CSVを読み込むと右側に表示され、銘柄チャートの現在時刻に同期して進みます。

3. 参照銘柄（1570 など）と日経換算

参照CSVには通常 1570（NEXT FUNDS 日経平均レバレッジ） を使いますが、1321 などの日経ETFや同業他社など任意の銘柄を読み込めます。

ヘッダーの倍率欄は参照銘柄の日経平均に対する連動倍率で、ファイル名のコードから自動設定されます（1570=2、1357=-2、1321=1、それ以外=1）。手入力で上書きできます。 「日経換算」は、参照銘柄の直近 5 本前からの変化率をこの倍率で割ったもので、日経平均のおおまかな地合いとして扱います。倍率が 1 の銘柄では「参照変化率」と表示します。

4. 仮想売買

実際の証券口座とは連動しない練習用のシミュレーションです。資金は無制限、空売り可。手数料・税金・部分約定・スリッページは考慮していません。

ボタンで発注する

  • 株数を入れて 買 成行 / 売 成行：現在の歩値で即時約定。
  • 指値欄に価格を入れて 買 指値 / 売 指値：買いは指値以下、売りは指値以上の歩値が出た時点で指値価格で約定。「現在値」ボタンで現在値を指値欄にコピーできます。
  • 指値取消：待機中の注文をすべて取消。売買リセット：建玉・損益・履歴をすべて初期化。
  • 反対売買は保有分を決済し、残りの株数でドテン（反対方向の建玉）になります。

チャートをクリックして発注する

チャート上の価格をクリックすると発注メニューが開きます。クリック位置の価格で 買/売 指値、買 逆指値（現在値より上）、売 逆指値（現在値より下）、買/売 成行、建玉があれば 全決済 成行と TP・LC の位置指定、全注文取消 が選べます。 価格は銘柄の呼値（読み込んだ歩値から推定）に丸められます。逆指値は到達時の歩値で約定します。

TP / LC（利確・損切）の自動設定

約定して建玉が残ると、TP% / LC%（平均取得単価からの％）にもとづいて利確ライン（TP）と損切ライン（LC）が自動で置かれます。 買い建てなら TP=上の売り指値 / LC=下の売り逆指値、売り建てなら TP=下の買い指値 / LC=上の買い逆指値です。数量は保有全量で、片方が約定するともう片方は消えます（OCO 相当）。

  • 注文ラインはドラッグで価格を動かせます。ドラッグ中もリプレイと約定判定は続きます（実戦と同じく、ドラッグ中に LC に到達すれば約定します）。
  • 注文ラインを動かさずにクリックすると、その注文の取消 / 全注文取消のメニューが出ます。TP/LC を取り消しても次の約定で置き直されます。
  • 建玉と TP/LC のラベルはチャート右側の余白に表示され、ローソク足に被りません。

建玉と損益、取引履歴

チャートの上に 建玉（正=買い建て、負=売り建て）・平均取得単価・実現損益・含み損益・合計損益・待機中の注文数 を表示します。 取引履歴には No / 時刻 / 種別 / 保有時間 / 株数 / 価格 / 収支 / 保有後 を記録し、損益はプラス＝赤、マイナス＝緑で表示します。約定位置はチャートに 買=赤▲ / 売=緑▼ で描かれます。

5. インジケーター

SQZ Momentum

LazyBear の Squeeze Momentum（ボリンジャーバンド 2.0σ とケルトナーチャネル 1.5 ATR、線形回帰）の移植です。値動きが縮んで力を溜めているのか、そこから上下どちらかに勢いが出ているのかを見る補助指標で、正（上向きの勢い）は赤系、負（下向きの勢い）は緑系で表示します。

RS（Relative Strength）

RS期間 本前と比べた 銘柄のリターン ÷ 参照銘柄のリターン − 1 です。0 より上（参照より強い）を赤、下（弱い）を緑で塗ります。参照チャート側には鏡像（参照 ÷ 銘柄 − 1）を表示します。

E/H 判定

売買の正解を出すものではなく、「いま攻めやすい形か」「過熱していて危ない形か」を見分けるための補助表示です。SMA5 / SMA25 / 出来高 / 参照銘柄の地合い を組み合わせた簡易判定で、SMA25 が揃うまでの最初の 25 本はシグナルが出ません。

  • E（Entry 候補）：日経換算で地合いが上向き、終値 > SMA5 > SMA25 で SMA5 が上向き、直近 10 本の高値ブレイクや上昇継続、出来高が細ったあとに増える／平均以上に入る、といった条件がそろった局面。
  • H（Heat＝過熱気味）：E 相当の条件に加えて、出来高の急増や強い陽線が出ている局面。伸びる可能性もありますが飛びつくと高値掴みになりやすいので、「強いが追いかけるには注意」という警告寄りの表示です。
  • 内部的には W（Watch＝監視）状態もありますが、情報量を抑えるためチャートには E/H のみ表示します。E/H ラベルは 5 本の間隔を空けてのみ新規表示されます。

7. データの取り扱いと注意

  • 本ツールは、利用者が各自の環境で取得した CSV をブラウザ上で可視化するためのものです。歩値データ・板情報・株価データ等は配布・再配信しません。
  • CSV は外部サーバーへ送信されず、利用者のブラウザ内で処理されます。
  • 利用者は、証券会社および情報提供元の利用規約に従って CSV データを利用してください。
  • 投資判断を目的としたものではありません。利用は自己責任でお願いします。
  • CSV 形式によっては正常に読み込めない場合があります。
  • 銘柄名の補完には JPX が公開している東証上場銘柄一覧をもとにした stock_master.js（銘柄コード→銘柄名のみ）を使っています。上場・廃止の反映には時間差があります。
  • チャート描画には Plotly.js を CDN から読み込むため、ページを開くときはインターネット接続が必要です。
