歩値CSVリプレイの使い方

SBI証券 Brisk からダウンロードした歩値CSV（約定ごとのCSV）をブラウザだけで読み込み、歩み値・ローソク足・VWAP・移動平均・出来高を当日の時間の流れに沿ってリプレイするデイトレ振り返りツールです。 仮想売買機能で、リプレイを見ながらエントリー・利確・損切りの練習もできます。ポジションは複数持てて、それぞれに利確（TP）・損切（SL）を置けます。

CSV はブラウザ内でのみ処理され、外部サーバーには送信されません。データはページを閉じると消えます。

1. Brisk から歩値CSVをダウンロードする

  1. SBI証券にログインし、国内株式 → Brisk を起動します。
  2. 銘柄を表示し、「歩値」タブから CSV をダウンロードします。
  3. ファイル名は Brisk のダウンロード名のまま qr-<銘柄コード>-<YYYYMMDD>.csv（例: qr-7203-20260917.csv）にしておくと、銘柄コード・日付・銘柄名が自動で入ります。 285A のような英字入りコードにも対応しています。

CSV の列は「値段, 株数, 金額, 時刻」（UTF-8、時刻は秒精度）を想定しています。列の順番はヘッダー名から自動で判定します。

2. 基本的な使い方

  1. 銘柄CSV にリプレイしたい銘柄の当日CSVを指定します。
  2. 前日終値 を手入力します（任意。前日比の表示にだけ使います。CORS の制約で自動取得はしていません）。
  3. ▶ 再生 を押すとリプレイが始まります。もう一度押す（または Space）と停止します。
  4. 11:30〜12:30 の昼休みは再生時に短縮します（前場引けの数秒後に、後場寄りの数秒前まで飛ばします）。

コントロール

足1分足 / 5分足。足は再生位置までの歩値から毎回組み立て直します。
速度0.25倍〜300倍。初期値は 1 倍（実時間）。
◀ / ▶足単位で戻る / 進む（← / → キーでも可）。進む側は再生と同じく約定判定あり、戻る側は判定なし。約定のない時間帯（昼休みなど）は飛ばします。

出来高「圧縮」は平方根スケールで大きな出来高をつぶして見やすくします。「通常」は実数。
約定音仮想売買の約定時に音を鳴らします（買い=高め、売り=低め、決済は 2 音）。

チャートの拡大・縮小（TradingView 風）

時間軸（横）と価格軸（縦）を別々に操作します。リプレイの再生中でも操作できます。

既定（自動）では時間軸は寄りから最新の足までの当日全体を表示し、足が増えるとその分だけ縮めて全体を表示し続けます。一度でも時間軸を操作すると手動になり、新しい足が出てもスクロールしません（≫ ボタンかチャートリセットで戻します）。

ホイール（チャート上）時間軸の拡大・縮小（上に回すと拡大）。縮小は今の足の本数に関係なく、1 日分（1分足で約 330 本、5分足で約 66 本）が収まるところまでできます。最新の足が見えているときは最新の足の位置を固定したまま、過去へスクロールしているときはカーソル位置の足を基準に拡大・縮小します。
ドラッグ（チャート上）左右で時間をスクロール。上下に動かすと価格軸が手動になり、上下にも動かせます。
価格目盛り（左）上へドラッグで拡大、下へドラッグで縮小（ホイールでも可）。価格軸は手動になります。ダブルクリックで自動に戻ります。
時刻目盛り（下）右へドラッグで拡大、左へドラッグで縮小。ダブルクリックで時間軸を既定に戻します。
A ボタン価格目盛りの左下。点灯中は価格軸が自動（表示中の足の高値・安値に合わせて縦を自動調整）。押すと手動 / 自動を切り替えます。
≫ ボタン最新の足が画面の右へ外れているときにチャート右下に出ます。押すと今の拡大率のまま最新の足へ移動します（手動のままなので、その後も自動ではスクロールしません）。
チャートリセット時間軸・価格軸とも既定（当日全体・価格自動）に戻します（R / Alt+R）。足の種類（1分/5分）を切り替えたときも時間軸は既定に戻ります。
  • 手動にしている軸は、「チャートリセット」の横に「時間:手動」「価格:手動」と表示し、ボタンが光ります。
  • 現在値が表示範囲の外にあるときは、右端の上下に ▲ / ▼ 付きの現在値を出します。

画面の見方

  • 左：歩み値テープ。約定ごとに値段・株数・金額（億円）・時刻を追加します。上昇＝赤、下落＝緑 の日本式配色です。
  • ヘッダーに現在値・前日比・VWAP・VWAP乖離・時刻を表示。「株探時系列」「株探基本」から株探の該当銘柄ページを開けます。
  • チャート：ローソク足（陽線=赤 / 陰線=緑）、VWAP（グレー）、SMA5（赤）/ SMA25（緑）、出来高（直前の足より増えれば赤、減れば緑）。現在値にはオレンジの破線と右端の価格ラベル。
  • チャートにカーソルを乗せると、その足の 時刻 / OHLC / 出来高 / VWAP / SMA5 / SMA25 をチャート見出しの右側に一行で表示します。カーソルを外すと最新の足の値に戻ります。
  • 下段：左が保有ポジション一覧、右が取引履歴です。

3. 仮想売買

実際の証券口座とは連動しない練習用のシミュレーションです。資金は無制限、空売り可。手数料・税金・部分約定・スリッページは考慮していません。

ポジションの考え方（複数ポジション・両建て）

  • 約定するたびに新しいポジション（#1, #2, …）ができます。同じ方向に買い増しても平均せず、別々のポジションとして持ちます。
  • 買いポジションを持ったまま売ると、決済ではなく売りの新規ポジションになります（両建て）。決済はポジションごとに行います（下記）。
  • ポジションごとに TP（利確）と SL（損切）を 1 本ずつ置けます。

ボタンで発注する

  • 株数を入れて 買 成行 / 売 成行：現在の歩値で新規ポジションを建てます。
  • 指値欄に価格を入れて 買 指値 / 売 指値：買いは指値以下、売りは指値以上の歩値が出た時点で指値価格で約定し、新規ポジションになります。「現在値」ボタンで現在値を指値欄にコピーできます。すでに約定条件を満たす価格なら現在値で即時約定します。
  • 注文取消：待機中の注文をすべて取消。全決済：すべてのポジションを現在値で決済。売買リセット：ポジション・注文・損益・履歴をすべて初期化。

TP / SL（利確・損切）

新しいポジションができると、TP% / SL%（建値からの％）にもとづいて、そのポジション専用の利確ライン（TP）と損切ライン（SL）が自動で置かれます。 買いポジションなら TP=建値より上 / SL=下、売りポジションなら TP=下 / SL=上です。％欄を空欄か 0 にすると自動では置きません。

  • TP に到達すると TP 価格で、SL に到達するとその時の歩値でポジションを決済します。
  • TP/SL は次の 3 つの方法で変更できます。
    • チャートのラインをドラッグ。ドラッグできるライン（TP / SL / 待機注文）は、チャート左端に ↕ TP・↕ SL・↕ 注文 のつまみと、右側のラベルに枠が付きます。カーソルを近づけるとラインが太くなり、つまみとラベルが線の色で塗られ、カーソルが上下矢印に変わります。ライン上のどこをつかんでも動かせます。ドラッグ中もリプレイと約定判定は続き、離した時点で新しい価格になります。表示範囲の外までドラッグして置くこともできます。
    • 保有ポジション一覧の TP / SL 欄に価格を入れて Enter。空欄にして Enter で外します。
    • チャートをクリックして「#1 買100 の TP をここに」などを選ぶ（下記）。
  • すでに到達している価格に TP/SL を置くと、現在値で即時に決済します。

チャートをクリックして発注する

チャート上の価格をクリックすると発注メニューが開きます。

  • クリック位置の価格で 買/売 指値、買 逆指値（現在値より上）、売 逆指値（現在値より下）、買/売 成行。逆指値は到達時の歩値で約定します。
  • ポジションがあれば、クリック位置に各ポジションの TP または SL を移す項目が出ます。現在値より上をクリックすると買いポジは TP・売りポジは SL、下なら逆になります。同じ方向のポジションが複数あるときは「買ポジ全部の TP をここに」のようにまとめて置けます。
  • 全決済 成行、全注文取消。

価格は銘柄の呼値（読み込んだ歩値から推定）に丸められます。

ラインをクリックする

  • 建値ライン（点線。ラベルに #番号・株数・建値・含み損益）：そのポジションの成行決済、外してある TP/SL を初期値で置き直す。
  • TP / SL ライン（破線）：その TP/SL を外す、そのポジションの成行決済。
  • 待機注文ライン（黄色の実線）：その注文の取消、全注文取消。ドラッグで価格を変えることもできます。

ラインのラベルはチャート右側の余白に表示され、ローソク足に被りません。近い価格のラベルは重ならないよう少しずらして表示します。

建玉と損益、取引履歴

チャートの上に 建玉（買い・売りそれぞれの合計株数とポジション数）・実現損益・含み損益・合計損益・待機中の注文数 を表示します。 保有ポジション一覧には # / 売買 / 株数 / 建値 / 損益（建値比％つき）/ TP / SL / 保有時間 と決済ボタンが並びます。 取引履歴には No / 時刻 / ポジション番号 / 種別（新規・決済と、成行・指値・TP・SL など）/ 保有時間 / 株数 / 価格 / 収支 / 建玉後 を記録し、損益はプラス＝赤、マイナス＝緑で表示します。約定位置はチャートに 買=赤▲ / 売=緑▼ で描かれます。

5. データの取り扱いと注意

  • 本ツールは、利用者が各自の環境で取得した CSV をブラウザ上で可視化するためのものです。歩値データ・板情報・株価データ等は配布・再配信しません。
  • CSV は外部サーバーへ送信されず、利用者のブラウザ内で処理されます。
  • 利用者は、証券会社および情報提供元の利用規約に従って CSV データを利用してください。
  • 投資判断を目的としたものではありません。利用は自己責任でお願いします。
  • CSV 形式によっては正常に読み込めない場合があります。
  • 銘柄名の補完には JPX が公開している東証上場銘柄一覧をもとにした stock_master.js（銘柄コード→銘柄名のみ）を使っています。上場・廃止の反映には時間差があります。
  • チャート描画には Plotly.js を CDN から読み込むため、ページを開くときはインターネット接続が必要です。
